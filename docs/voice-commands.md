# 语音命令速查 Voice Commands

## 两种入口

### 1. 全局语音命令（推荐）—— 任意页面

任意页面 **长按 C 键**（1.3 秒）→ 蓝灯快闪（开始录音）→ 说指令 → 3.5 秒自动停止 → 橙灯（后台转写）→ **一次刷屏直达目标页**。

> 唤起阶段不刷屏（最小路径），识别成功后才刷屏一次。

### 2. 待办页录音 —— 「小彩」前缀防误判

在语音待办页录音，**转写文本含「小彩」**才会走命令；否则一律存为普通待办（100% 不误删）：

| 你说 | 结果 |
|------|------|
| `小彩打开日历` | 切到日历页 |
| `小彩，帮我记住买牛奶` | 去前缀后存待办「帮我记住买牛奶」 |
| `明天买菜` | 存普通待办（不误判） |

## 命令清单

| 命令 | 说法示例 | 效果 |
|------|---------|------|
| 定时提醒 | `提醒我3点开会` / `3点半打卡` / `记得明天9点吃药` | 到点语音播报 + 屏幕提示 |
| 天气 | `今天天气` / `天气怎么样` | 切日历页 + 刷新天气 + 语音播报 |
| 资讯早报 | `读新闻` / `早报` | 切早报页 + 语音朗读第一条 |
| 番茄钟 | `开始番茄` / `专注` | 启动 25 分钟专注 + 语音确认 |
| 切页 | `打开日历` / `去看待办` / `切到考点` / `显示二维码` | 直达对应页 |
| 直呼页名 | `日历` / `待办` / `考点` / `仪表盘` / `二维码` | 整句精确匹配，防误判 |

## 交互反馈

| 阶段 | LED | 说明 |
|------|-----|------|
| 录音中 | 蓝灯快闪 | 3.5 秒自动停 |
| 转写中 | 橙灯慢闪 | SiliconFlow SenseVoice 后台转写 |
| 识别失败 | — | 提示「识别失败，请重试」 |
