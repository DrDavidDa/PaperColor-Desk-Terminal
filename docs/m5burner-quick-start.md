# M5Burner 小白上手教程

## 先记住一件事

烧录完成后，**不需要先在 TF/microSD 卡上建文件才能配置 WiFi**。最简单的方法是用手机配网：

1. 设备开机。如果没有保存过 WiFi，设备会自动显示 WiFi 配网说明。
2. 手机连接设备屏幕显示的热点，例如 `PaperColor-XXXXXX`。
3. 如果手机提示“此网络无互联网”，选择“继续连接/保持连接”。
4. 扫描设备上的二维码，或在手机浏览器打开 `http://192.168.4.1`。
5. 选择家里的 WiFi，输入密码，点击“保存并连接”。
6. 等待设备显示连接成功。约 10 秒后设备关闭临时热点，手机再切回家里的 WiFi。

没有自动弹出网页时，直接打开 `http://192.168.4.1`。以后要重新配置 WiFi，进入二维码页并长按 B。

## 只想离线使用

在设备的 WiFi 配网页面，**短按 C 键**选择“离线使用”。设备会记住这个选择，以后开机直接进入本地模式，不再反复打开配网页面。

离线模式仍可使用日历、内置考点、SD 卡内容、传感器和本地语音；天气、新闻、网络时间和云端服务需要 WiFi。以后进入二维码页长按 B 即可重新配置。

## 使用 SD 卡文件配置（备用方法）

只有需要通过文件配置时，才使用此方法：

1. 将 SD 卡格式化为 FAT32。
2. 在 SD 卡**根目录**放置一个文件，文件名必须是 `config.ini`。
3. 可以复制仓库中的 [`config.ini.example`](../config.ini.example) 作为模板。
4. Windows 需要打开“显示文件扩展名”，确认文件不是 `config.ini.txt`。
5. 至少填写以下两行，然后保存、弹出 SD 卡、插入设备并重启：

```ini
use_wifi=true
wifi_ssid=你的WiFi名称
wifi_pass=你的WiFi密码
```

SSID 和密码必须替换成实际内容。文件不能叫 `wifi.ini`、`config.txt`，也不能放在 `config/` 子目录中。

## SD 卡内容目录

SD 卡不是烧录固件的必要条件，但自定义内容需要它：

```text
SD卡根目录/
├── config.ini
├── cards/              # 自定义考点卡片
├── qr/                 # png / jpg / bmp 二维码图片
├── voice/              # 语音文件
├── todo.txt            # 语音待办文字
└── reminders.txt       # 定时提醒
```

SD 卡没有插好时，设备仍可使用手机配网和内置功能；只是无法读取这些自定义文件。

## M5Burner 说明

M5Burner 只负责烧录固件，不会自动读取电脑 WiFi，也不会替用户生成 SD 卡上的 `config.ini`。烧录后请优先使用上面的手机配网流程。
